# Contratto condiviso eseguibile

Questa directory contiene `gatt.profile.json`, fixture interoperabili, codec C in `c/` e implementazioni di riferimento in `reference/`. App, firmware, generatori e test condividono questi asset: i percorsi eseguibili restano stabili.

La documentazione è nell’[indice dei protocolli](../docs/protocols/README.md). I risultati dei singoli incrementi sono in [docs/verification/](../docs/verification/README.md).

Verifica dalla radice con `python3 scripts/check_shared_contract.py` oppure `python3 scripts/check_host.py`.
