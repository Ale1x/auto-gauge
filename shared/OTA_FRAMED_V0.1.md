# OTA framed session v0.1

24 October2026. Development-only binding of OTA_TRANSFER_V0.1 payloads to existing AG framing1; no new frame kind or change to existing JSON RPC. An OTA session exclusively owns its packet pipe/connection. A platform must choose the session route locally; arbitrary packet content never switches a live JSON RPC link into OTA. No native BLE route, radio activation, product keys, health/rollback/floor or flash execution is enabled by this increment.

## Frames and ordering

OTA requests use kind1, responses kind2, request IDs exactly1,2,…,UINT32_MAX, nonzero. One outstanding request, response ID equals request ID. Payload request≤1036bytes, response exactly16bytes; ordinary AG magic/version/reserved/length/CRC rules hold. CRC/IDs never authenticate. AG chunks1…512 and actual connection write limit determine fragmentation, no fixed MTU. Existing frame/stream codecs remain unchanged.

The target endpoint is initialized once for one trusted nonzero lease and requires an already initialized ag_ot_owner_t plus trusted local allowed/clock hooks. Owner/trust/platform lifetimes exceed endpoint. Endpoint init never resets/reinitializes the owner. A reconnect uses a fresh endpoint and cannot reset a previously admitted one-transfer/boot owner. An alien lease feed/poll/output/close leaves this endpoint and owner byte-identical and invokes no callbacks.

Feed reassembles but **does not call the owner**. A valid complete request is copied into bounded staged storage. It must be the sole frame with no trailing partial bytes in the completing chunk: concatenated complete frames or trailing prefix fault before dispatch. A separate step validates security/deadlines then calls the owner exactly once and stages a framed ACK. Sequence ID advances for that dispatched request even when the OTA status is non-ok; a replay/skipped/zero ID is a protocol fault, never a retry. While staged or ACK pending, feed returns busy and does not mutate pending work. Reentry returns busy without touching state. No observer infers that callbacks had no side effects from failed framing/delivery.

Before processing input, owner dispatch, ACK emission and periodic poll, sample trusted allowed then fresh monotonic clock. Clock regression, revocation, malformed frame/order, frame timeout, pending-request/ACK timeout or matching close seals endpoint terminal. Timeout starts when a complete request is staged and covers step→ACK consumption; it is absolute and not refreshed by polling. Owner periodic poll remains required even without bytes. Wrong lease never runs these checks on the current owner.

On matching terminal close/fault, if the owner currently has an active transfer bound to this same lease, issue one internal terminal cancel through its existing API (allowed may already be revoked; its guard then faults/cleans up). Do not reset the owner, cancel another lease or retry a cleanup. Selected/faulted/idle owners invoke no new mutation during close. Owner's selection/cleanup uncertainty remains intact. Endpoint cannot prove platform write completion or boot health. take_output produces a complete copied frame only after current authorization; caller must still check actual transport send/confirmation and close on failure.

## Swift packet transport

Implement OTATransferTransport over existing GaugePacketPipe and frame/reassembler APIs. Default host-development gate CLOSED. readyConnection is only observation; no scan/pairing/connect is started implicitly. Open binds a nonzero generation and actual maximum write length once. This transport never reopens/reuses a closed session, never shares a pipe with RPC, never retries writes/requests and disconnects the bound generation on failure.

exchange validates request payload syntax, serializes one operation across awaits, uses next monotonically increasing request ID, fragments encoded AG packet to min(maximumWriteBytes,512), and requires exactly one matching response kind2/ID with exact16byte valid OTA ACK. Reject extra complete frames and trailing partial bytes in that same received chunk. Frame assembly deadline and sender absolute deadline both apply; validate receivedAt is not in the future or earlier than this exchange and honor cancellation. Generation/readiness must match before/after async IO; any error after binding closes terminally and disconnects, even if ATT write may already have succeeded. A concurrent exchange returns busy without closing in-flight work.

currentGeneration observes that the bound pipe remains ready with same generation/write limit; it does not assert radio authentication. It must not disrupt an in-flight exchange just because it is queried concurrently. close prevents old deferred callbacks from publishing success; actor epoch guards around every await, including pipe-ready/write/receive, reject close/reentry races. Cooperative pipe cancellation is a contract, as in existing RPC client; no physical security is inferred from conformance.

## Evidence

Host C CLI fixture receives chunks over test-only u32LE-length stdin messages and emits length-prefixed framed ACKs. It feeds+steps+takes the production framed endpoint, owner and codecs; behavioral backend only, explicit --trusted-fixture-maintenance required. Swift test pipe adapts that process to actual GaugePacketPipe fragmentation and exercises OTATransferSender→packet transport→AG stream→C endpoint→owner. Additional tests inject stale IDs/generations, corruption, fragmentation, extra/partial frames, timeout, disconnect and uncertain ACK/select. CLI framing is host-only and does not represent ATT/radio.
